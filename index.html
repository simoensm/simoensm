How I build

Built with Claude,
understood by me.

I use Claude, Anthropic's AI assistant, as a pair programmer and research partner. Most of the tools on this site were built that way, this website included.

01

Smart

I bring the problem, the plan and the decisions. Claude speeds up everything around them: drafting code, exploring an API I don't know yet, reviewing a design, writing tests. I describe exactly what I want, read every change, and run and test it myself.

02

Ethical

I'm open about it, like here. For coursework I follow each course's rules and say where AI helped. Nothing personal or confidential goes into a prompt, I check facts and sources instead of taking them on trust, and I only hand in work I can explain line by line.

03

A way to learn

I ask why, not only what. When Claude writes something new to me, I have it explain the approach, then I change or rebuild it myself. It works like a patient tutor: languages and tools I didn't know became projects I can now build on my own.

The clearest example is Research Vault: an AI research agent that answers only from my own notes, with citations, and never invents a source.
